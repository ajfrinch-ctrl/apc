# ফ্যাক্টরি রিসেট — ডাটাবেজ ক্লিয়ার ও নতুন এডমিন একাউন্ট (২০২৬-১০-০৮)

ইনস্টিটিউশনের সব ডেটা মুছে **একদম শুরু থেকে** চালু করার দুটি উপায়। দুটির লক্ষ্য এক:
ডাটাবেজ খালি হলে লগইন পেজে আবার **«প্রথমবার ব্যবহার করছেন? Admin Account তৈরি করুন»**
ফ্লো ফিরে আসে (`js/admin-initialization.js` ক্লাউডে নতুন করে যাচাই করে)।

> ⚠️ দুটি উপায়ই **অপরিবর্তনীয় (undo নেই)**। আগে এডমিন প্যানেল → ডেটা →
> **ব্যাকআপ ও রিস্টোর** থেকে ব্যাকআপ ডাউনলোড করে রাখুন।

---

## উপায় ১ — অ্যাপ থেকেই (সুপারিশকৃত)

এডমিন প্যানেল → **ডেটা** → **«সম্পূর্ণ ডাটাবেজ রিসেট»** কার্ড:

1. **সম্পূর্ণ ডাটাবেজ রিসেট করুন** চাপুন।
2. নিশ্চিত করতে বর্তমান **এডমিন পাসওয়ার্ড** লিখুন।
3. অ্যাপ ক্লাউড ডাটাবেজ নোড-ধরে-নোড মুছে ফেলে (`js/realtime-sync.js` →
   `resetCloudDatabase`): শিক্ষার্থী, লেনদেন, রুটিন, নোটিশ, একাডেমিক, কোর্স কনটেন্ট,
   শিক্ষক অ্যাসাইনমেন্ট, সেটিংস, পরীক্ষা ডাটাবেজ, ইউজারনেম রেজিস্ট্রি, স্টাফ ডিরেক্টরি,
   সব শিক্ষার্থী লগইন রেকর্ড, চারটি স্টাফ অ্যাকাউন্ট ও `system/adminInitialized` মার্কার।
4. তারপর এই ডিভাইসের লোকাল স্টোরেজ পুরো মুছে ব্রাউজার লগইন পেজে ফেরত পাঠায়।
5. লগইন পেজে এবার **নতুন এডমিন অ্যাকাউন্ট** তৈরি করুন (প্রথম-ব্যবহার ফ্লো)।

**প্রয়োজন:** ইন্টারনেট সংযোগ (ক্লাউড মুছতে হবে) + ডাটাবেজ রুলের **নতুন সংস্করণ ডিপ্লয়**।
রিপোজিটরির রুল-জেনারেটর এখন ডিলিট সমর্থন করে
(`tools/rtdb-rules/build-interim-rules.mjs`); পুরোনো রুল ডিপ্লয় করা থাকলে রিসেট
`permission-denied` দেখাবে। টার্মিনালে একবার:

```bash
firebase deploy --only database
```

**সীমাবদ্ধতা:**

- অন্য ডিভাইসে পুরোনো ডেটা থেকে গেলে সেই ডিভাইস অনলাইনে এলে ডেটা আবার ক্লাউডে
  ফিরে আসতে পারে — রিসেটের পর পুরোনো ডিভাইসগুলো থেকেও অ্যাপ খুলে রিসেট করুন
  (বা সেগুলোর সাইট ডেটা মুছুন)।
- পুশ-টোকেন রেজিস্ট্রেশন লেখা-যায়-পড়া-যায়-না (write-only) নোড, তাই অন্য ডিভাইসের
  টোকেন মোছা যায় না; পুরোনো টোকেনে পাঠানো পুশ শুধু ব্যর্থ হয় — ক্ষতিকর নয়।
- রিসেট ব্যর্থ হলে (নেটওয়ার্ক/রুল সমস্যা) **লোকাল ডেটা মোছা হয় না** — অসম্পূর্ণ
  অবস্থা এড়ানোর জন্য ইচ্ছাকৃত।

## উপায় ২ — Firebase Console থেকে (সার্ভার-সাইড)

`docs/RTDB-REBUILD-RUNBOOK.md`-এর «পুরোনো ডেটা পুরোপুরি মুছে নতুন শুরু» ধাপ:

1. [Firebase Console](https://console.firebase.google.com) → প্রকল্প
   **`active-plus-coaching`** → Build → Realtime Database → **Data** ট্যাব।
2. ⋮ মেনু → **Delete data** (বা `activePlusSync` root নোড মুছুন)।
   - বিকল্প: `firebase database:remove / --project active-plus-coaching`
3. **প্রতিটি ডিভাইসে** অ্যাপের লোকাল ডেটাও মুছতে হবে — নইলে ব্রিজ লোকাল কপি
   আবার ক্লাউডে তুলে দেবে। এডমিন ডিভাইসে উপায় ১-এর রিসেট বাটনই সবচেয়ে সহজ।
4. অ্যাপ খুললে লগইন পেজে নতুন এডমিন অ্যাকাউন্ট তৈরির ফ্লো দেখা যাবে।

## রিসেটের পরে যাচাই

1. লগইন পেজে **«প্রথমবার ব্যবহার করছেন? Admin Account তৈরি করুন»** দেখা যাচ্ছে।
2. নতুন এডমিন তৈরি হলে `admin.apc` ইউজারনেমে প্যানেলে প্রবেশ করা যায়।
3. এডমিন → ডেটা → সংগ্রহ তালিকায় সব কাউন্ট শূন্য।
4. টপবারের উপরের বর্ডার নীল = ক্লাউড সিঙ্ক লাইভ।
